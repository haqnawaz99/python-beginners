# ================================================
# Module 0 - Lesson 1: What is Python?
# ================================================
# Course: Learn Python Step by Step
# Audience: Ages 10-16, Zero prior experience
# ================================================

# Python is a programming language.
# A programming language lets us give instructions to a computer.
# Just like we use Urdu or English to talk to people,
# we use Python to talk to computers.

# Why Python?
# - Easy to read and write (almost like English)
# - Free to download and use
# - Used all over the world
# - Used in websites, games, science, AI, and more

# Who uses Python?
# - NASA (space research)
# - Google, YouTube, Instagram
# - Scientists, doctors, teachers
# - Students like YOU!

# ------------------------------------------------
# What can we do with Python?
# ------------------------------------------------

# 1. Show a message on screen
print("Assalamu Alaikum! Welcome to Python.")

# 2. Do calculations
print("5 + 3 =", 5 + 3)

# 3. Ask the user for information
# (We will learn this soon)

# 4. Make decisions
# (We will learn this too)

# ------------------------------------------------
# How does Python work?
# ------------------------------------------------
# We write instructions in a file ending with .py
# Python reads our instructions from top to bottom
# Each line is one instruction
# Python follows our instructions one by one

print("Python reads this line first.")
print("Then this line.")
print("Then this line last.")

# ------------------------------------------------
# Your First Look at Python Code
# ------------------------------------------------
# The word   print   tells Python: show this on screen
# The text inside " "  is what gets shown
# Every print statement shows one line

print("My name is Ahmed.")
print("I am learning Python.")
print("Bismillah - let us begin!")

# Module 0 - Lesson 2: Your First Program
# ================================================
# Learn: print(), running a Python file
# ================================================

# ------------------------------------------------
# The print() function
# ------------------------------------------------
# print() is the most basic Python command.
# It shows text or numbers on the screen.
# Whatever you put inside the brackets gets printed.

print("Hello, World!")
print("Assalamu Alaikum!")
print("I am a Python programmer now.")

# ------------------------------------------------
# Printing numbers
# ------------------------------------------------
# Numbers do NOT need quotation marks

print(10)
print(100)
print(2025)

# ------------------------------------------------
# Printing calculations
# ------------------------------------------------
# Python can calculate and print the answer

print(5 + 3)        # Addition
print(10 - 4)       # Subtraction
print(3 * 4)        # Multiplication
print(10 / 2)       # Division

# ------------------------------------------------
# Printing text AND numbers together
# ------------------------------------------------
# Use a comma to combine text and numbers in print()

print("My age is", 14)
print("Pakistan has", 220000000, "people")
print("There are", 5, "prayers in a day")

# ------------------------------------------------
# Multiple print statements
# ------------------------------------------------
# Each print() starts on a new line

print("Fajr")
print("Dhuhr")
print("Asr")
print("Maghrib")
print("Isha")

# ------------------------------------------------
# Empty print() adds a blank line
# ------------------------------------------------
print("First section")
print()
print("Second section after blank line")

# How to RUN this file

# ================================================
# Module 0 - Lesson 3: Comments
# ================================================
# Learn: What are comments, how to write them
# ================================================

# ------------------------------------------------
# What is a comment?
# ------------------------------------------------
# A comment is a note for the programmer.
# Python IGNORES comments completely.
# Comments start with the # symbol.
# Use comments to explain your code.

# This is a comment. Python will not run this line.
print("Python runs this line.")   # This comment is after code - also ignored

# ------------------------------------------------
# Why write comments?
# ------------------------------------------------
# 1. To explain what your code does
# 2. To remind yourself later
# 3. To help other people understand your code
# 4. To temporarily turn off a line of code

# ------------------------------------------------
# Examples of useful comments
# ------------------------------------------------

# Print the Islamic greeting
print("Assalamu Alaikum wa Rahmatullahi wa Barakatuh")

# Show the number of Surahs in the Quran
print("The Quran has", 114, "Surahs")

# Show Pakistan's independence year
print("Pakistan was created in", 1947)

# ------------------------------------------------
# Turning off code with a comment
# ------------------------------------------------
# Sometimes we want to stop a line from running.
# Just put # in front of it.

print("This line runs.")
# print("This line is turned off - Python ignores it.")
print("This line runs too.")

# ------------------------------------------------
# Good commenting habit
# ------------------------------------------------
# Write comments that explain WHY, not just WHAT.

# Bad comment (obvious - no need to say this):
# print the word hello
print("Hello")

# Good comment (explains something non-obvious):
# Greet the student by name before starting the lesson
print("Welcome, Ahmed! Let us learn Python today.")

# ------------------------------------------------
# Summary
# ------------------------------------------------
# # starts a comment
# Python ignores all comments
# Comments are for humans, not computers
# Good programmers write helpful comments

print()
print("You now know about comments. Well done!")

# ================================================
# Module 0 - Lesson 4: Common Errors
# ================================================
# Learn: What errors look like, how to read them,
#        and how to fix the 3 most common ones
# ================================================

# ------------------------------------------------
# Errors are NORMAL - do not be afraid!
# ------------------------------------------------
# Every programmer sees errors. Even experts.
# An error means Python found something it cannot understand.
# Python tells you WHAT went wrong and WHERE.
# Read the error message - it is helping you!

# ------------------------------------------------
# Error Type 1: SyntaxError
# ------------------------------------------------
# Syntax means the rules of writing Python.
# A SyntaxError means you broke a rule.
# Most common cause: missing bracket, missing quote.

# WRONG - missing closing quote:
# print("Assalamu Alaikum)
# Error: SyntaxError: EOL while scanning string literal

# WRONG - missing closing bracket:
# print("Hello"
# Error: SyntaxError: unexpected EOF while parsing

# CORRECT:
print("Assalamu Alaikum")
print("Hello")

# ------------------------------------------------
# Error Type 2: NameError
# ------------------------------------------------
# A NameError means you used a word Python does not know.
# Most common cause: typo in a function name.

# WRONG - typo: 'Print' should be 'print' (lowercase p)
# Print("Hello")
# Error: NameError: name 'Print' is not defined

# WRONG - typo in function name
# priint("Hello")
# Error: NameError: name 'priint' is not defined

# CORRECT - Python is case sensitive, always lowercase 'print'
print("No errors here!")

# ------------------------------------------------
# Error Type 3: IndentationError
# ------------------------------------------------
# Python uses spaces/indentation to organize code.
# We will see this more when we learn if/loops.
# For now: do NOT add extra spaces at the start of a line.

# WRONG - unexpected indent:
# print("Hello")
#     print("Indented by mistake")
# Error: IndentationError: unexpected indent

# CORRECT - all basic statements start at the left edge
print("Line 1")
print("Line 2")

# ------------------------------------------------
# How to READ an error message
# ------------------------------------------------
# When you see an error, look for:
# 1. The FILE name - which file has the error
# 2. The LINE number - which line caused it
# 3. The ERROR TYPE - SyntaxError, NameError, etc.
# 4. The MESSAGE - description of the problem

# Example error message:
#   File "0_4_common_errors.py", line 45, in <module>
#     Print("Hello")
#   NameError: name 'Print' is not defined
#
# This tells us: line 45, we wrote 'Print' but it should be 'print'

# ------------------------------------------------
# Golden Rule
# ------------------------------------------------
# When you see an error:
# Step 1 - Do NOT panic
# Step 2 - Read the error message carefully
# Step 3 - Find the line number it mentions
# Step 4 - Fix the mistake
# Step 5 - Run again

print()
print("Errors are your teacher - they show you exactly what to fix!")
print("Every expert programmer fixes errors every single day.")
